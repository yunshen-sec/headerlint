# Security policy

## Safe use

`headerlint` is a defensive review tool. Only inspect response samples and
public URLs that you own or are explicitly authorized to test. Prefer the
offline sample mode for development and use synthetic fixtures in tests.

## Reporting a vulnerability

Please do not put credentials, private URLs, or exploit details in a public
issue. Open a private GitHub security report when available, or contact the
maintainer through the GitHub profile with a minimal reproduction and the
affected version.
